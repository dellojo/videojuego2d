## 1. Contexto del videojuego

*Resident Cementary* es un videojuego en 2D con temática de terror, ambientado en un cementerio con una atmósfera oscura inspirada en Halloween. El jugador controla a un personaje que debe enfrentarse a diferentes criaturas que aparecen y se desplazan por el escenario, como cuervos, zombis, cultistas y parásitos.

El videojuego cuenta con un sistema de puntuación y un sistema de vidas que permite al jugador perder hasta cinco vidas cuando las criaturas entran en contacto con el personaje. Fue desarrollado utilizando HTML, CSS y JavaScript, incorporando elementos gráficos, movimiento de objetos, detección de colisiones e interacción mediante el mouse.

## 2. Objetivo del videojuego

El objetivo principal de *Resident Cementary* es conseguir la mayor puntuación posible al eliminar las criaturas que aparecen en pantalla, evitando que estas entren en contacto con el personaje principal.

El jugador comienza con cinco vidas y pierde una cada vez que una criatura toca al personaje. Por lo tanto, debe mantener la atención tanto en los objetivos que necesita eliminar como en los movimientos de los enemigos para evitar perder todas sus vidas.


## 3. Justificación

El desarrollo de *Resident Cementary* permite poner en práctica los conocimientos de programación y graficación mediante la creación de un videojuego interactivo. La incorporación de diferentes criaturas, animaciones y un sistema de vidas permite que el juego tenga mayor dificultad y que el jugador deba prestar atención a lo que sucede en pantalla.

Asimismo, la implementación de la detección de colisiones permite comprender cómo se identifica el contacto entre objetos dentro de un entorno virtual. El sistema de puntuación y las vidas también ayudan a establecer reglas de juego y objetivos claros para el usuario.

La temática de terror se eligió para darle una identidad visual al proyecto y crear una experiencia entretenida mediante escenarios oscuros, criaturas y elementos relacionados con el género.

## 4. Operación del videojuego

Para jugar *Resident Cementary*, el usuario debe abrir la página web desde un navegador. Al iniciar, se muestra el escenario del cementerio, el personaje principal y las diferentes criaturas que se desplazan por la pantalla.

El funcionamiento del videojuego es el siguiente:

1. **Inicio del juego:** se carga el escenario, el personaje principal y las criaturas que aparecen en pantalla. El jugador comienza con cinco vidas.
2. **Eliminación de criaturas:** el jugador utiliza el mouse para hacer clic sobre los enemigos y obtener puntos.
3. **Sistema de puntuación:** cada vez que el jugador acierta sobre una criatura, aumenta la puntuación.
4. **Sistema de vidas:** cuando una criatura entra en contacto con el personaje principal, el jugador pierde una de sus cinco vidas.
5. **Supervivencia:** el jugador debe eliminar las criaturas y evitar el contacto con ellas para conservar sus vidas durante la partida.
6. **Reinicio:** el botón de reinicio permite comenzar una nueva partida y restablecer el progreso del juego.
